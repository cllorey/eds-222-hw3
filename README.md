# EDS 222 HW 3

## Get started

Begin by cloning this repo to your directory on Workbench. Do not change the name! In order to receive credit and feedback, your folder name must match this repo's name exactly. Make sure to complete all the exercises on Workbench - that's what we'll use for grading and feedback.

## Part 1: Generalized linear models

Demonstrate your understanding of generalized linear models by completing the exercises in `glm.qmd`. You'll return to the soil lead data from the neighborhoods around the former Exide battery recycling facility to model the probability that a property exceeds the EPA's soil lead screening level using logistic regression, then simulate air quality exceedance counts to fit a Poisson regression and check that it recovers your parameters.

The rubric by which your work will be assessed is in `glm-rubric.md`.

Please note: some details are deliberately unspecified. For example, in section 3 you will choose your own parameter values for a simulation. Use your judgement to make appropriate choices for these details.

## Part 2: Final project first draft

Keep building toward your final project! `first-draft.md` walks you through setting up a dedicated repository for your project, organized following the [EDS 214 folder organization system](https://eds-214-reproducibility-m26.github.io/course-materials/resources/folder-organization.html) and documented following the [MEDS README guidelines](https://ucsb-meds.github.io/README-guidelines/). In that repository, you'll write a complete first draft of your blog post that addresses every criterion in the [final project rubric](https://eds-222-stats-f26.github.io/final-project.html#rubric), building on your exploratory analysis (`eda.qmd`) and proposal (`proposal.qmd`), and publish it with GitHub Pages. Submit it by adding links to your project repository and your published blog post in `project-link.md` in this repo. Like all final project checkpoints, the first draft is ungraded. That said, the more complete your draft, the more useful the feedback you'll get before the final draft is due!
